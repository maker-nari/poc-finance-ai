# 📑 AI 월말 정산 도우미 POC 프로토타입

### 🚀 [실시간 라이브 데모 바로가기](https://poc-finance-ai.streamlit.app/)

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://poc-finance-ai.streamlit.app/)

> **"AI 초안과 담당자의 검토를 결합하여, 3일 걸리던 월말 정산표 작성을 1일 이내로 단축합니다."**

이 프로젝트는 엑셀/CSV로 업로드된 지출 내역과 증빙 자료를 AI가 자동으로 매칭하고, 계정과목 초안을 제안하여 회계 담당자의 업무 효율성을 검증하기 위한 **POC(Proof of Concept)용 프로토타입**입니다.

> 현재 프로토타입의 AI 분석 기능은 실제 AI API 호출이 아니라, PoC 검증을 위한 규칙 기반 mock 로직으로 구현되어 있습니다.

---

## 🎯 POC 핵심 목표

1. **시간 절감**: 단순 반복적인 증빙 대조 및 계정과목 분류 시간을 70% 이상 단축할 수 있는지 검증.
2. **누락 탐지**: 증빙 누락 의심 항목을 식별하고, 담당자 요청 메시지 초안을 생성.
3. **사용자 경험**: AI 초안을 담당자가 손쉽게 검토·수정하고, 최종 판단권을 유지하는 UI 구현.

## ✨ 주요 기능

### 1. 스마트 데이터 업로드 & 확인

- 지출 내역(카드/계좌), 증빙 자료 목록, 계정과목 기준표 업로드 지원
- 업로드 즉시 필드 확인 및 미리보기 제공
- **샘플 데이터 실행**: 파일 없이도 버튼 하나로 전체 프로세스 테스트 가능

### 2. AI 자동 분석 (Drafting)

- **증빙 매칭**: 거래일자, 거래처, 금액을 비교하여 증빙 유무 판정
- **계정과목 제안**: 기존 기준표 및 기본 규칙을 기반으로 비용 항목 및 코드 자동 분류
- **분석 신뢰도 표시**: AI 분류의 자신감을 점수로 표시하여 집중 검토 대상 식별

### 3. 담당자 검토 및 실시간 수정

- **실시간 자동 매핑**: 비용 항목 변경 시 계정과목 코드가 즉시 연동되어 자동 업데이트
- **증빙 누락 관리**: 누락자별 맞춤형 요청 메시지 초안 생성 및 복사 기능
- **Human-in-the-loop 구조**: AI 초안은 담당자가 검토·수정한 뒤 최종 확정

### 4. 성과 대시보드 및 리포트

- **분석 지표**: 처리 시간, AI 초안 수정 비율 실시간 계산
- **최종 리포트**: 검토가 완료된 데이터를 정제하여 CSV 파일로 다운로드
- **OKR 달성 판정**: 핵심 지표 달성 여부에 따라 확산/개선/중단 의사결정 가이드 제공

## 📌 POC 검증 관점

본 POC는 AI 초안 생성 기능을 도입했을 때 **회계 담당자의 업무 시간이 실제로 단축되는지**, 그리고 **AI의 분석 결과가 실무에 적합한 수준인지**를 데이터로 검증하는 것을 목적으로 합니다.

단순한 데모 앱이 아니라, 실제 PoC 운영 시 필요한 처리 시간, 수정 비율, 누락 탐지 적중률, 사용자 체감 만족도를 함께 수집하여 AI 적용 가능성을 판단합니다.

---

## ✨ 핵심 업데이트 (Ver 2.0)

1. **정밀 시간 측정**: 데이터 로드 시점부터 최종 확정 시점까지의 전체 리드타임 및 AI/사용자 구간별 소요 시간을 초 단위로 기록합니다.
2. **OKR 자동 판정**: 설정된 4가지 핵심 결과(Key Results) 달성 여부를 기반으로 사업 확산/재실험/중단 여부를 자동 제안합니다.
3. **운영 로그 추출**: 성능 분석을 위한 모든 지표를 JSON 및 CSV 로그로 출력하여 사후 분석 기능을 강화했습니다.
4. **실시간 데이터 동기화**: `st.data_editor`를 활용하여 사용자가 항목 수정 시 계정과목 코드가 즉시 업데이트되는 반응형 UI를 구현했습니다.

## 📊 주요 측정 지표 및 OKR 판정 기준

| 지표 | 목표 기준 | 측정 내용 |
| :--- | :--- | :--- |
| **작성 시간** | 1영업일 이내 단축 가능성 | 전체 프로세스 소요 시간 및 구간별 병목 확인 |
| **AI 수정 비율** | 30% 이하 | AI 초안 대비 담당자가 직접 수정한 건수의 비율 |
| **탐지 적중률** | 70% 이상 | AI가 의심한 누락 건 중 실제 누락으로 확인된 비율 |
| **체감 만족도** | 4점 이상 / 5점 만점 | 사용자 편의성 및 업무 효율 개선에 대한 정성 점수 |

### 의사결정 기준

- **KR 4개 중 3개 이상 달성**: 확산 검토
- **KR 4개 중 2개 달성**: 개선 후 재실험
- **KR 4개 중 1개 이하 달성**: 중단 또는 축소

## 🛠 사용 방법 (Test Scenario)

1. **데이터 준비**  
   상단 버튼을 통해 **샘플 데이터**를 로드합니다.  
   이때부터 업무 시간이 측정됩니다.

2. **AI 분석**  
   `AI 초안 생성 시작` 버튼을 클릭하여 매칭 및 분류 결과를 확인합니다.

3. **검토 및 수정**
   - 증빙 누락 탭에서 담당자별 요청 문구를 확인합니다.
   - 상세 검토 탭에서 잘못 분류된 비용 항목을 수정합니다.
   - 비용 항목 수정 시 계정과목이 자동 변경되는지 확인합니다.

4. **최종 확정**  
   검토가 끝나면 `최종 확정` 버튼을 클릭합니다.

5. **결과 분석**  
   하단에 생성된 **성과 대시보드**와 **OKR 판정 결과**를 확인하고 운영 로그를 다운로드합니다.

## 📊 운영 데이터 수집 및 성능 분석

본 프로토타입은 단순히 AI 초안을 생성하는 데서 끝나지 않고, PoC 실행 결과를 정량적으로 분석할 수 있도록 운영 로그를 수집합니다.

수집 항목은 다음과 같습니다.

- 전체 처리 건수
- AI 분석 소요 시간
- 담당자 검토 소요 시간
- 전체 업무 소요 시간
- AI 초안 수정 항목 수
- AI 초안 수정 비율
- 누락 의심 항목 수
- 실제 누락 적중률
- 사용자 체감 효율 점수
- OKR 달성 여부
- 확산/개선/중단 판단 결과

이를 통해 AI 도입 효과를 감이 아니라 데이터 기반으로 판단할 수 있습니다.
