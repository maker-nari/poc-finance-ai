# 📑 AI 월말 정산 도우미 POC 프로토타입

> **"AI 초안과 담당자의 검토를 결합하여, 3일 걸리던 월말 정산표 작성을 1일 이내로 단축합니다."**

이 프로젝트는 엑셀/CSV로 업로드된 지출 내역과 증빙 자료를 AI가 자동으로 매칭하고, 계정과목 초안을 제안하여 회계 담당자의 업무 효율성을 검증하기 위한 **POC(Proof of Concept)용 프로토타입**입니다.

---

## 🎯 POC 핵심 목표
1. **시간 절감**: 단순 반복적인 증빙 대조 및 계정과목 분류 시간 70% 이상 단축.
2. **누락 탐지**: AI를 통한 실시간 증빙 누락 항목 식별 및 요청 자동화.
3. **사용자 경험**: AI의 초안을 담당자가 손쉽게 수정하여 최종 판단권을 유지하는 UI 구현.

---

## ✨ 주요 기능

### 1. 스마트 데이터 업로드 & 확인
- 지출 내역(카드/계좌), 증빙 자료 목록, 계정과목 기준표 업로드 지원.
- 업로드 즉시 필드 확인 및 미리보기 제공.
- **샘플 데이터 실행**: 파일 없이도 버튼 하나로 전체 프로세스 테스트 가능.

### 2. AI 자동 분석 (Drafting)
- **증빙 매칭**: 거래일자, 거래처, 금액을 비교하여 증빙 유무 판정.
- **계정과목 제안**: 기존 기준표 및 기본 규칙을 기반으로 비용 항목 및 코드 자동 분류.
- **분석 신뢰도 표시**: AI 분류의 자신감을 점수로 표시하여 집중 검토 대상 식별.

### 3. 담당자 검토 및 실시간 수정
- **실시간 자동 매핑**: 비용 항목 변경 시 계정과목 코드가 즉시 연동되어 자동 업데이트.
- **증빙 누락 관리**: 누락자별 맞춤형 요청 메시지(초안) 자동 생성 및 복사 기능.

### 4. 성과 대시보드 및 리포트
- **분석 지표**: 처리 시간, AI 초안 수정 비율 실시간 계산.
- **최종 리포트**: 검토가 완료된 데이터를 정제하여 CSV 파일로 다운로드.
- **OKR 달성 판정**: KPI 달성 여부에 따른 확산/개선/중단 의사결정 가이드 제공.

- **언어**: Python 3.9+

- **데이터 처리**: Pandas, Openpyxl

## 🚀 실행 방법

### 로컬 환경 실행
1. 저장소를 클론합니다.
```bash
git clone https://github.com/your-username/poc-finance-ai.git
cd poc-finance-ai
```

2. 필수 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

3. 앱을 실행합니다.
```bash
streamlit run app.py
```

## 📂 폴더 구조 및 데이터 형식
```text
project/
├── app.py              # 애플리케이션 메인 소스 코드
├── requirements.txt    # 의존성 패키지 목록
└── 샘플데이터/           # 테스트용 샘플 CSV 파일 보관
    ├── 지출내역.csv
    ├── 증빙자료.csv
```

### 필수 데이터 필드
- **지출내역**: 거래일자, 거래처명, 금액, 사용자, 사용부서
- **증빙자료**: 파일명, 거래일자, 거래처명, 금액
- **계정과목 기준표**: 거래처 키워드, 비용 항목, 계정과목
